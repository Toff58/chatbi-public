# 用户体验改进说明

更新时间：2026-05-20

## 原体验

原页面是单个表单输入框：用户输入问题后，下方一次性输出结论、图表和明细。这个形式能跑通，但不利于连续追问，也缺少可快速试用的样例入口。

## 本次改动

| 模块 | 改动 | 价值 |
| --- | --- | --- |
| 页面布局 | 从居中单表单改为宽屏问数工作台 | 图表和表格展示空间更大。 |
| 输入方式 | 使用 `st.chat_input()` | 更符合问数和对话式 BI 的心智。 |
| 会话历史 | 用 `st.session_state.messages` 保留本次会话问题和答案 | 用户可以连续比较多次查询结果。 |
| 示例问题 | 在侧边栏放 5 个高频问题按钮 | 新用户不用猜问法，可以直接体验核心能力。 |
| 结果呈现 | 结论优先，图表和明细放入 tabs | 减少首屏拥挤，结果层次更清楚。 |
| 运行反馈 | 保留 `st.status()`，并展示耗时和返回行数 | 用户能感知查询状态和结果规模。 |
| 调试信息 | 不在前端展示 SQL/RAG/指标 | 面向客户的界面更干净，完整过程仍写入日志。 |

## 2026-05-20 补充改动

| 模块 | 改动 | 价值 |
| --- | --- | --- |
| 口径说明 | “休闲娱乐、年轻、下沉、高收入、低收入”等默认口径会在结果上方提示 | 客户能看到系统采用的统计范围。 |
| 数据范围 | 其他月份、趋势、环比、同比类问题会直接提示当前只有 2025-07 单月数据 | 避免给出无法被数据支持的趋势结论。 |
| 图表策略 | 单值结果不画图；多行结果按排行、占比、多指标、趋势选择图表 | 降低无意义图表，提升结果可读性。 |
| 结果下载 | 非空结果支持 CSV、Excel 下载；有图表时支持 SVG 下载 | 满足问数后的复用、汇报和二次分析。 |
